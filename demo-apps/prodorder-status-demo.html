About This System

The Production Order Schedules System is the root schedule source in the scheduling portfolio: it reads live SAP-based production order data and renders it as an interactive Gantt-style view organized by workcenter. Other tools in the portfolio — the Andon Board, Backend Status, and Schedule Visualization systems — all reference production orders that originate from this view, so it is the single place schedulers and supervisors go to see "what is planned, where, and when" across the shop.

  • Root Gantt-by-workcenter view feeding Andon Board, Backend Status and Schedule Visualization.
  • Live SAP-based production order schedule with start/end windows per routing step and workcenter.
  • Sortable source data grid with per-order drill-down: routing steps, remaining hours, linked sales order.
  • Workcenter and status filters to focus scheduling conversations on a single line or cell.
  • Simulation-style what-if view (in the real system) for testing re-slots without touching SAP.
