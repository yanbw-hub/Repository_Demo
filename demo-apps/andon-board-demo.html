Live Floor Comments

The Production Andon Board is a large-screen, workcenter-based wallboard designed to be viewed from across the shop floor. It combines live production confirmations with planned hours and time windows so supervisors, operators and the scheduling team can align on what is running now, what is next, and how each center is tracking against plan — without opening a report.

  • Real-time status per workcenter (running / at-risk / stopped) using a simple traffic-light color code.
  • Today's production sequence with the current and next orders, plus plan-hours-vs-actual tracking.
  • Backlog and backlog-risk counts so teams can see queued work piling up behind a center.
  • A live floor-comments feed for shift handovers and stand-up conversations, visible on the same screen.
