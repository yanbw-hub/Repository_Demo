About this system

The real Machine Load Recalculation Studio is Trench Canada's new online successor to the long-standing Machine Load VBA workbook that schedulers used to hand-balance winding and VPI capacity. It re-implements and enhances those VBA calculations as a proper web application, and adds an embedded rebalancing assistant that proposes how to redistribute orders across machines — while every change stays a local "what-if" plan until a scheduler chooses to act on it.

  • Machine-by-machine Gantt (WIND1–WIND5, VPI) showing every scheduled order against its PMAD date and available capacity.
  • Click-to-edit "what-if" drawer — adjust an order's start date, duration, or PMAD to simulate moving or resizing it, without touching SAP.
  • Enhances the original Machine Load VBA tool's balancing logic with a modern, always-on visual load view instead of a static spreadsheet snapshot.
  • Embedded AI rebalancing concept: suggests order shifts to relieve an overloaded machine, shown here as a client-side simulated suggestion.
  • Overrides are saved locally as a draft plan for review — nothing is written back to production systems automatically.
