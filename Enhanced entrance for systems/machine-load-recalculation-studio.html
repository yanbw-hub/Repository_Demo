Machine Load Recalculation Studio

Dual-mode scheduling system for SAP-based winding schedule recalculation, manual sequence editing, machine-load Gantt visualization, and AI-assisted balancing with downloadable output workbooks.

AI mode & Manual mode SAP bundle + workbook export Gantt & table views

How to use this System

  • Log in first, then choose either AI Mode or Manual Mode.
  • AI Mode provides Gantt Visualization, Table Source and AI Workspace.
  • Manual Mode provides Gantt Visualization and Table Source.
  • Default SAP files can be loaded from the server, or local workbooks can be uploaded from device.
  • All recalculation and optimization results can be downloaded as output workbooks after a successful run.

Guide Manual

This guide explains how to use the main pages inside the Machine Load Recalculation Studio. The frontend provides a login page, mode selection, machine-load Gantt boards, editable source tables, AI balancing, and manual recalculation workflows.

  1. Login page & mode selection

    The system opens with a login page and allows the user to enter either AI Mode or Manual Mode. After a successful login, the page switches into the selected workspace shell.

    • Use AI Mode when you need SAP-driven recalculation and AI balancing.
    • Use Manual Mode when you want to upload a schedule file, edit sequence directly, and run a lighter recalculation path.
  2. AI Mode · Gantt Visualization

    The AI-mode Gantt page is the high-level machine-load view. It shows current machine allocation and the latest schedule state after SAP import or recalculation.

    • Use this page to understand machine occupancy and compare the effect of optimization rounds.
    • It is the fastest page for spotting overloaded machines or abnormal schedule clustering.
  3. AI Mode · Table Source

    The AI-mode table shows the editable machine-load schedule source table. It displays the current schedule rows and attribute columns, and supports direct source review before entering the AI workspace.

    • Use this page when you want to review the current schedule row-by-row before optimization.
    • It pairs naturally with the Gantt page: table for detail, Gantt for pattern recognition.
  4. AI Mode · AI Workspace

    The AI Workspace is the main control center for SAP bundle upload, schedule source selection, unsupervised balancing, recalculation results, machine load status, and result download.

    • Choose whether the AI should use the current in-system schedule or an imported local sheet as its source.
    • Upload or auto-load the required SAP files, then run recalculation or AI optimization.
    • After completion, download the generated workbook directly from the output section.
  5. Manual Mode · Table Source

    The Manual Mode Table Source page supports schedule-file upload, dense table editing, pick / move operations, and manual recalculation without entering the AI workflow.

    • Upload a local .xlsx / .xls / .xlsm schedule file from device.
    • Edit row position and source values directly in the table, then run recalculation.
    • When the response returns successfully, the page switches to the Manual Gantt tab automatically.
  6. Manual Mode · Gantt Visualization

    This page visualizes the recalculated manual schedule using the manual machine list and current output rows.

    • Use it immediately after manual recalculation to verify whether the row move or sequence edit produced the intended result.
    • Download the recalculated workbook when the visual result is acceptable.
  7. Download outputs & troubleshooting

    Both AI and Manual workflows produce downloadable result workbooks. When calculation fails, the frontend surfaces the returned error message from the API.

    • Use the generated download links after recalculation, manual recalculation, or AI optimization.
    • When an endpoint fails, open the browser Network tab to inspect returned ok:false and error text.

General Suggestion: use Gantt Visualization for pattern-level review, Table Source for row-level inspection and direct edits, and the AI Workspace when you need full SAP-driven recalculation and balancing.

System Link & API guide for Data Source

Open the frontend from internal network, then use your assigned credential to log in. The frontend is designed for desktop usage and connects to a dedicated API service for default SAP loading, recalculation, AI optimization and output download.

Open Machine Load Recalculation Studio

Demo preview Demo preview - API Status: Internal

1. Health & default SAP loading

GET /api/health
Returns a simple health payload for the recalculation service.
GET /api/default-sap-files
Load the server-side default SAP bundle and calendar file metadata, including file preview and base64 payload.

2. Manual workflow endpoints

POST /api/manual-recalculate
Run manual recalculation using uploaded schedule rows plus calendar data. Accepts schedule rows, schedule columns and config such as machine list, shift pattern and manual sequence preservation.
GET /api/download-manual/:id
Download the generated workbook from a successful manual recalculation run.

3. AI / SAP bundle recalculation

POST /api/recalculate-bundle
Run the standard SAP-bundle recalculation path using required uploads such as chars, hours, lead orders, prod orders, sales orders and calendar, with optional materials, lock and imported schedule sheet.
GET /api/download/:id
Download the result workbook from a successful standard recalculation run.

4. AI optimization workflow

POST /api/ai/optimize-recalculate-bundle
Run AI optimization plus recalculation using the same SAP bundle, AI machine rules, and optimization scoring logic.
GET /api/download-ai/:id
Download the AI-optimized workbook after the service returns a successful result.

5. Core file assumptions

Required SAP keys
chars, hours, leadOrders, prodOrders, salesOrders and calendar are required for the standard SAP-bundle flow.
Default server-side file map
Default SAP loading expects Calendar.xlsx, Chars.xls, Hours.xls, Lead Orders.xls, Prod Orders.xls, Sales Orders.xls and Lock.xlsx in the configured server-side SAP data directory.

6. Responses & errors

All endpoints return JSON. Success payloads include result rows and optional download information. On failure, the API returns HTTP 4xx / 5xx codes together with ok:false or an error message for troubleshooting in the browser Network tab.
