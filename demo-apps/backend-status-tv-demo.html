About this system

The real Backend Status System is a shop-floor order-tracking tool used by Trench Canada's coils production team. This wallboard variant shares the exact same underlying data model and order pipeline as the standard desktop Backend Status app, but is purpose-built for a big-screen TV mounted on the shop floor — larger type, higher contrast, and far less UI chrome, so status is readable from across the room without a mouse or keyboard.

  • Same order & workcenter data model as the desktop Backend Status app (STRIP, CRIMP, WELD2, BLAST, CLEAN, PAINT, TESTLAB, DETAIL, CRATE).
  • Kanban-style columns group orders by pipeline stage instead of raw grid rows, for quick at-a-glance scanning.
  • Color-coded status dots and card borders flag at-risk and overdue orders instantly from a distance.
  • Designed to auto-refresh unattended on a mounted display, with no operator interaction required.
